# AI Value Engineers Website

A modern, interactive website showcasing AI implementation services with a focus on value-based pricing.

## Features

- **SEO Optimized**: Complete meta tags for search engines and social media
- **Interactive Platform Carousel**: Apple Watch-style draggable interface featuring 41+ enterprise platforms
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **Contact Form**: Direct email integration
- **Modern Animations**: Smooth transitions and engaging user experience

## Files

- `index.html` - Main website structure
- `styles.css` - All styling and animations
- `script.js` - Interactive carousel and form functionality

## Local Testing

Simply open `index.html` in any modern web browser.

## Deployment Options

### Option 1: Netlify (Recommended - Free & Easy)

1. Go to [netlify.com](https://netlify.com)
2. Drag and drop this folder into Netlify
3. Configure your custom domain `aivalueengineers.com`
4. Done! Your site is live with HTTPS

### Option 2: Vercel (Free & Fast)

1. Go to [vercel.com](https://vercel.com)
2. Import this folder
3. Configure domain settings
4. Deploy

### Option 3: GitHub Pages (Free)

1. Create a GitHub repository
2. Upload these files
3. Enable GitHub Pages in repository settings
4. Point your domain to GitHub Pages

### Option 4: Traditional Web Hosting

1. Upload all files to your web hosting via FTP/SFTP
2. Point `aivalueengineers.com` to your hosting
3. Ensure files are in the public_html or www directory

## Customization

### Update Contact Email
Edit `script.js` line with email address (currently: `er.ndrio@gmail.com`)

### Add/Remove Platforms
Edit the `platforms` array in `script.js`

### Change Colors
Modify CSS variables in `styles.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    /* etc... */
}
```
